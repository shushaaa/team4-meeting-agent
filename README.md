# 이직 도우미 에이전트 · 최소 MVP

평소 업무 메모를 검증 가능한 경력 기록으로 저장하고, 누적 기록으로 기본 이력서 한 종류를 만드는 파일 기반 MVP입니다.

## 목표

```text
업무 메모 → 사실 검증 → 기록 축적 → 기본 이력서
```

공고 맞춤, 경력기술서, 자기소개서 등 확장 기능을 빼고 이 흐름의 기본 품질만 검증합니다.

## 구성

| 담당자 | 에이전트 | 역할 |
| --- | --- | --- |
| 은선 | `career-record` | 업무 메모 구조화와 보완 질문 |
| 예진 | `career-verify` | 사실·수치·본인 역할 독립 검증 |
| 예진 | `career-resume` | 검증 기록으로 기본 이력서 생성 |
| 예진 | 메인 세션 | 경로 선택과 순서 제어 |

기초정보는 에이전트가 아니라 `profile/profile-template.md` 양식으로 최초 1회 입력합니다.

## 고정 경로

### A · 업무 기록

```text
career-record → career-verify → records/<record_id>.md
```

### B · 기본 이력서

```text
profile/profile.md + records/*.md → career-resume → output/base-resume.md
```

## 공식 파일

```text
profile/profile.md              # 사용자가 입력한 기초 경력정보
records/WORK-YYYYMMDD-NNN.md   # 검증된 업무 기록
output/base-resume.md          # 유일한 최종 출력
```

별도 경력 원장, 단계별 결과 파일, 버전 파일, 변경 이력, 중복 후보, 정상 실행 로그는 만들지 않습니다.

## 실행 순서

1. 압축을 풀고 이 폴더를 VS Code로 엽니다.
2. Claude Code를 실행하고 새 세션을 시작합니다.
3. `/agents`에서 `career-record`, `career-verify`, `career-resume`을 확인합니다.
4. `PROMPTS.md`의 1번부터 순서대로 실행합니다.
5. 화면 구조는 `web/index.html`에서 확인합니다. 이 화면은 실제 파일 저장과 연결되지 않은 정적 프로토타입입니다.

## 상태

- `확인`: 원문·사용자 답변·수치 근거로 확인됨
- `미확인`: 근거가 없거나 본인 역할을 구분할 수 없음

기본 이력서에는 `확인` 정보만 사용합니다.

## 제외 범위

- 공고 분석과 맞춤 문서
- 경력기술서·자기소개서·면접 질문
- 중복 자동 병합
- 신뢰도 점수
- 음성·첨부파일 자동 입력
- DOCX·PDF 변환
- 데이터베이스와 외부 서비스 연결

## 완료 기준

1. `/agents`에 3개 에이전트가 보인다.
2. 답변이 없어도 경로 A가 검증까지 완료된다.
3. 모든 업무 기록에 `record_id`가 있다.
4. 근거 없는 수치와 미확인 역할이 기본 이력서에 들어가지 않는다.
5. 기본 이력서의 모든 사실 문장에 `[근거: PROFILE]` 또는 `[근거: WORK-...]`가 있다.

## 데모 데이터

팀 저장소와 발표에는 `samples/`의 가상 인물·가상 프로젝트만 사용합니다. 실제 회사 자료는 공개 저장소에 올리지 않습니다.
