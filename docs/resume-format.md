# 기본 이력서 형식

유일한 출력 파일은 `output/base-resume.md`입니다.

## 구조

```text
# 표시 이름
현재 직무·헤드라인

## 프로필 요약
## 경력 이력
## 주요 업무·프로젝트
## 역량
## 보완 필요
```

## 문장 규칙

- 프로필에서 가져온 사실: `[근거: PROFILE]`
- 업무 기록에서 가져온 사실: `[근거: WORK-YYYYMMDD-NNN]`
- 업무 문장: `문제·목표 → 본인 행동 → 결과`
- 확인된 결과가 없으면 결과를 억지로 붙이지 않습니다.
- 미확인 정보는 본문에 쓰지 않고 필요한 경우 `보완 필요`에 항목명만 적습니다.

## 금지

- 근거 없는 수치
- 팀 성과를 본인 단독 성과로 표현
- 업무 기록에 없는 역량 추가
- 근거 표시 없는 사실 문장
